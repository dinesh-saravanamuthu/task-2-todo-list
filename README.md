# TaskFlow — To-Do List Web App

A front-end-only To-Do List built for **Task 2: Web Development Internship** using HTML, CSS, and Vanilla JavaScript.

## Features

- Add new tasks
- Add tasks with the Enter key
- Mark tasks as complete / active
- Delete individual tasks
- Filter by All, Active, and Completed
- Clear all completed tasks
- Live remaining-task counter
- Empty-state messages
- Responsive design for desktop and mobile
- No page reload required
- Uses DOM manipulation and JavaScript event listeners
- No frameworks or paid tools

## How to run

### Option 1 — VS Code + Live Server
1. Open this folder in VS Code.
2. Install the free **Live Server** extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

### Option 2 — Direct browser
Open `index.html` in Chrome.
